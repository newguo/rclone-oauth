# rclone-oauth

Static GitHub Pages site used as the public application homepage and policy pages for a personal Google OAuth client.

Purpose:

- authorize a private rclone-based backup workflow;
- copy the owner's GitHub repository data to the owner's Google Drive;
- provide the application homepage, privacy policy, and terms links required by Google Auth Platform.

Published pages:

- Home: https://newguo.github.io/rclone-oauth/
- Privacy Policy: https://newguo.github.io/rclone-oauth/privacy.html
- Terms of Service: https://newguo.github.io/rclone-oauth/terms.html

This repository contains no OAuth client secret, refresh token, rclone configuration, or GitHub Actions secret.
