Privacy Policy

Last updated: September 23, 2026

This OAuth application is a private tool used solely by its owner to automate backups from the owner's GitHub repositories to the owner's Google Drive using rclone and GitHub Actions.

Google Drive access

The application requests Google Drive access only for the purpose of creating, updating, synchronizing, and managing backup files required by the owner's backup workflow.

Data handling

Repository data is transferred from GitHub to the owner's Google Drive. OAuth credentials used by the automation are stored as encrypted GitHub Actions secrets. The application does not sell user data, use user data for advertising, or intentionally share user data with unrelated third parties.

Users

This application is intended for personal use by its owner and is not offered as a public service.
